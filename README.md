# Oct 20 · Welcome to 23

一份为 23 岁生日做的全屏互动 H5。现在的主页（`index.html`）是尾声的 **3D 星河蛋糕 + 许愿贺卡**：可拖动旋转、轻触烛火吹灭、白烟与星屑烟花之后，贺卡逐行浮现。

原先的「烫金邀请函 + 五幕故事」版本完整保留在 `story.html`，随时可以回去看，不影响主页。

## 预览

直接双击 `index.html` 即可；更推荐起一个本地静态服务器：

```bash
cd "C:/Users/Administrator/Desktop/hb" && python -m http.server 5173
```

然后打开：

- 蛋糕主页：http://localhost:5173/
- 香槟金配色：http://localhost:5173/?theme=gold
- 原五幕版本：http://localhost:5173/story.html

### 3D 星河蛋糕（主页）

- 深蓝蛋糕体 + 青 / 金 / 粉三色流光丝带，顶部奶油与数字蜡烛（2 / 3），默认使用「深海星河」配色。
- 两支蜡烛始终正面朝向镜头，无论怎样转动蛋糕，阅读顺序都保持「23」而不会变成「32」。
- 星屑与祝词一起缓慢公转；轻触烛火 → 白烟、星屑烟花 → 贺卡浮现，再轻触蛋糕可重新点亮。
- 手机竖屏下蛋糕约占屏宽 2/3，提示语会自动落在托盘下方；贺卡整体上移，避开底部水印。
- 贺卡顶部贴了三张手绘贴纸照片（`assets/photos/sticker-1/2/3.webp`，由根目录的 `s1/s2/s3.png` 裁边压缩而来），像随手贴在卡片上的装饰。
- 贺卡右下角是一枚手绘小头像落款（`assets/photos/signature-avatar.png`，由根目录的原始 PNG 裁切而来）。想换图直接替换这个文件；如果浏览器还显示旧图，把 `index.html` 里的 `?v=2` 改成 `?v=3` 即可强制刷新。
- 顶部标题是一张手绘字图（`assets/photos/hbfont-title.webp`，由根目录的 `hb2.png` 裁边压缩而来），不再使用文字标题；想换图直接替换这个 webp 即可。
- 正文字体 Noto Serif SC、英文字体 Cormorant Garamond 都做了子集化放在 `assets/fonts/`，页面不再请求 Google Fonts，国内可正常加载。Noto 的可见汉字子集不含数字，所以另打了一份 `noto-serif-sc-digits.woff2`（等高 lining 数字），避免数字回退到 Cormorant 的旧式字形后「2」比「3」矮一截。
- 右上角圆形音符按钮控制背景音乐（与五幕版共用的纯合成生日曲，主页默认开启、进页面就尝试播放，音量 0.55）；按钮图标只反映真实播放状态，被浏览器自动播放策略拦下时显示冷色呼吸圈，轻触后变金色。吹灭蜡烛时会额外叠加一串清脆的风铃音。

## 换成你们的照片与名字（五幕版）

### 1. 名字

编辑 `js/config.js`：

```js
herName: "她的名字",
yourName: "你的名字",
birthdayLabel: "2026.10.20"
```

### 2. 照片

把照片放进 `assets/photos/`，文件名与 `js/config.js` 里的 `photos` 对应即可，例如：

```js
photos: {
  ch1_lake: "assets/photos/ch1-lake.jpg",
  ch1_dune: "assets/photos/ch1-dune.jpg",
  ...
}
```

九个位置分别是：

| 配置键 | 场景 | 建议 |
| --- | --- | --- |
| `ch1_lake` | 湖岸薄纱迎风 | 竖版全身 |
| `ch1_dune` | 沙丘墨镜 | 竖版半身 |
| `ch2_hat` | 牛仔帽 × 碧绿河湾 | 竖版 |
| `ch2_boardwalk` | 湖畔木栈道 | 竖版 |
| `ch2_scarf` | 湖风围巾 | 竖版 |
| `ch3_gown` | 草地浅粉长裙托腮 | 竖版 |
| `ch3_birch` | 白桦林回眸提裙 | 竖版 |
| `ch3_veil` | 珠饰头纱回眸 | 竖版 |
| `ch3_star` | 林间高光时刻 | 竖版 |

留空时会显示与场景呼应的金色线稿占位卡，不会出现破图。照片建议长边 1600px 左右、竖构图；`object-fit: cover` 会自动裁切。


## 小提示

- 蛋糕主页不锁滚动；音乐默认开启，浏览器允许自动播放时进页面就响。被自动播放策略拦下时，右上角按钮会显示为「待开启」（冷色呼吸圈），第一次轻触页面任何地方都会立即接上；按钮只在实际出声时才点亮成金色。五幕版首次进入会锁定滚动，拆封邀请函后解锁，这是刻意的仪式感。
- 五幕版的音乐只在用户点击后启动（移动端浏览器自动播放策略），点铃铛也可以单独开启。
- 两版都已适配 `100dvh`、刘海安全区、小屏（≤600px 高度）与横屏。
