# 照片放置说明

把照片放进这个文件夹，然后在 `js/config.js` 的 `photos` 里填入对应路径，例如：

```js
ch1_lake: "assets/photos/ch1-lake.jpg"
```

推荐文件名：

- `ch1-lake.jpg` —— 湖岸薄纱迎风
- `ch1-dune.jpg` —— 沙丘墨镜
- `ch2-hat.jpg` —— 牛仔帽河湾
- `ch2-boardwalk.jpg` —— 湖畔木栈道
- `ch2-scarf.jpg` —— 湖风围巾
- `ch3-gown.jpg` —— 草地浅粉长裙
- `ch3-birch.jpg` —— 白桦林回眸
- `ch3-veil.jpg` —— 珠饰头纱
- `ch3-star.jpg` —— 林间高光

竖构图效果最好；照片会被自动裁切填满相框。未配置或加载失败时，会显示香槟金线稿占位插画。
